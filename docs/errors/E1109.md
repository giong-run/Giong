# GIONG-E1109: cannot decode the response body

Raised by giong-http's client, reading a body. In code: `giong::error::Code::HttpClientDecode`.

## What happened

The body could not be read the way it was asked for: `Response::text` found bytes that are not UTF-8.

## How to fix it

- Read it as bytes with `Response::body`, and decode it with the character set its `Content-Type` names.
- A compressed body is never decoded by the client; it does not ask for compression.
