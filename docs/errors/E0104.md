# GIONG-E0104: no DNS server configured

Raised by `giong::net` name resolution. In code: `giong::error::Code::NoDnsServer`.

## What happened

A name had to be looked up in DNS, but `/etc/resolv.conf` names no DNS server (it is missing, empty, or has no `nameserver` line).

## How to fix it

- Add a `nameserver` line to `/etc/resolv.conf`.
- Or use an IP address, or a name listed in `/etc/hosts`, which need no DNS.
