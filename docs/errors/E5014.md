# GIONG-E5014: the port is in use

Raised by the `giong` command (giong-cli): `giong doctor` and `giong dev`. In JSON output: `"code": "GIONG-E5014"`.

## What happened

Another process listens on the port the service is configured to use, so the service cannot bind it.

## How to fix it

- Stop the other process (`ss -ltnp` on Linux or `lsof -i :PORT` on macOS shows which one), or use another port.
- An older `giong dev` of the same project may still run in another terminal.
