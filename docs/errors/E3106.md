# GIONG-E3106: wrong number of rows

Raised by giong-mysql, `query_one`, `query_opt` and `insert`. In code: `giong::error::Code::MysqlRowCount`.

## What happened

`query_one` expects exactly one row and `query_opt` at most one, and the statement returned another number; or `insert` found no `AUTO_INCREMENT` id to return.

## How to fix it

- Use `query_opt` when the row may be missing, and `query` when there can be several.
- Add a `LIMIT 1` or a unique condition if exactly one row is meant.
- Use `execute` for statements that generate no id.
