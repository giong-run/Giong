# GIONG-E3207: Redis reply too large

Raised by giong-redis, reading a reply. In code: `giong::error::Code::RedisTooLarge`.

## What happened

A reply was larger than `Config::max_reply_size` (64 MiB by default). The limit keeps one command from using all of a worker's memory. The reply was read and thrown away as it arrived; the connection stays usable.

## How to fix it

- Read less at a time: `SCAN`, `HSCAN` and `ZRANGE` with a range or `LIMIT` instead of `KEYS`, `HGETALL` or a whole sorted set.
- Raise `Config::max_reply_size` if the reply really has to be this big.
