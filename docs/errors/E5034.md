# GIONG-E5034: the project's crates do not build on Windows

Raised by the `giong` command (giong-cli): `giong new`, on Windows, up to giong-cli 1.5.1. In JSON output: `"code": "GIONG-E5034"`.

## What happened

Up to giong 1.4, only the runtime crate (`giong`) built on Windows, so `giong new` warned that the project it wrote would not build there. Since 1.5 every crate builds and passes its tests on Windows, and CI builds and tests the projects `giong new` writes on Windows. giong-cli 1.5.2 and later no longer raise this code.

## How to fix it

- Update giong-cli: `giong upgrade --self`, then `giong upgrade` in the project to move it to the current giong crates.
- The project then builds on Windows as it is. Production still runs best on Linux, where io_uring is available.
