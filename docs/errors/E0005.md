# GIONG-E0005: unexpected result from the kernel

Raised by the runtime's I/O operations. In code: `giong::error::Code::Unexpected`.

## What happened

The kernel returned something giong does not expect, such as received data without a buffer or a datagram from an unknown address family. It points to a bug in giong or in the kernel.

## How to fix it

- Please report it at https://github.com/giong-run/Giong/issues with the message, your kernel version (`uname -r`) and, if you can, a way to reproduce it.
- Running the same program on another kernel version helps tell the two apart.
