# GIONG-E3102: cannot connect to MySQL

Raised by giong-mysql, opening a connection. In code: `giong::error::Code::MysqlConnect`.

## What happened

Opening the connection failed before authentication: name resolution, the TCP or Unix socket connection, TLS, or the connect timeout (10 seconds by default). The cause is in the message. An unknown database (error 1049) and a full server (1040, too many connections) are reported with this code too.

## How to fix it

- Check the host, the port (3306 by default) and the database name, and that the server accepts connections from here (`bind_address`, firewalls).
- For TLS errors, see the TLS code in the message (`GIONG-E2xxx`); the server's certificate must name the host you connect to.
- giong-mysql needs MySQL 8.0 or later; older servers are refused with this code.
- If the server is slow to accept, raise `Config::connect_timeout`.
