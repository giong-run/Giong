# GIONG-E5009: the code does not compile

Raised by the `giong` command (giong-cli): `giong check` and `giong dev`. In JSON output: `"code": "GIONG-E5009"`.

## What happened

The compiler reported an error. `giong dev` keeps the last build that worked running until the code compiles again.

## How to fix it

- Read the compiler's message in the finding (file, line, and its own explanation), fix the code, save.
- `rustc --explain E0XXX` explains the compiler's own codes.
