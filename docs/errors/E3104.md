# GIONG-E3104: MySQL server error

Raised by giong-mysql, running a statement. In code: `giong::error::Code::MysqlServer`.

## What happened

The server reported an error for a statement. The message contains the server's text, `Error::code()` returns MySQL's error number, such as 1062 for a duplicate key or 1213 for a deadlock, and `Error::db()` gives the SQLSTATE too.

## How to fix it

- Look the number up in the MySQL manual ("Server Error Message Reference").
- Match on `Error::code()` in code, not on the message, which the server may translate.
- 1213 (deadlock) means the server rolled the transaction back: run it again from the start. 1205 (lock wait timeout) rolls back only the statement.
- 3024 means the statement ran longer than `Config::statement_timeout`; MySQL enforces it on SELECT only.
