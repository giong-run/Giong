# GIONG-E0002: the kernel is too old

Raised by the runtime, when a worker starts. In code: `giong::error::Code::KernelTooOld`.

## What happened

The kernel is missing an io_uring feature giong needs: registering a ring of receive buffers (`IORING_REGISTER_PBUF_RING`) failed. It arrived in Linux 5.19 and works reliably from 6.0, the oldest kernel giong supports.

## How to fix it

- Run on Linux 6.0 or newer; 6.1 or newer is faster (giong then uses `IORING_SETUP_DEFER_TASKRUN`). `uname -r` shows the version.
- On a managed platform, pick a node image with a newer kernel.
