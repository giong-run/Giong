# GIONG-E5037: .mcp.json is not valid JSON

Raised by the `giong` command (giong-cli): `giong ai init` (also run by `giong new`). In JSON output: `"code": "GIONG-E5037"`.

## What happened

`giong ai init` adds two MCP servers to `.mcp.json` (`giong`, this command over stdio, and `giong-service`, the running service's giong-mcp), keeping every other server and key. The file is not one JSON object with an object under `mcpServers`, so giong left it untouched rather than guess.

## How to fix it

- Fix the JSON (the message gives the line and column), then run `giong ai init` again.
- Or add the servers by hand: `"giong": {"command": "giong", "args": ["mcp"]}` under `mcpServers`.
