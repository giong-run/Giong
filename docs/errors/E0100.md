# GIONG-E0100: invalid address

Raised by `giong::net`, when an address is given as a string. In code: `giong::error::Code::InvalidAddress`.

## What happened

An address string is not `"host:port"`: the port is missing, is not a number from 0 to 65535, or the string is empty.

## How to fix it

- Write the host and the port: `"localhost:8080"`, `"10.0.0.5:5432"`, `"[::1]:443"` (brackets around an IPv6 address).
- A URL is not an address: take the host and the port out of it first.
