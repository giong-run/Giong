# GIONG-E3004: PostgreSQL server error

Raised by giong-postgres, running a statement. In code: `giong::error::Code::PostgresServer`.

## What happened

The server reported an error for a statement. The message contains the server's text, and `Error::code()` returns its SQLSTATE, such as `23505` for a unique violation or `40001` for a serialization failure.

## How to fix it

- Look the SQLSTATE up in the PostgreSQL manual (appendix A, "PostgreSQL Error Codes").
- Match on `Error::code()` in code, not on the message, which the server may translate.
- `40001` and `40P01` mean the transaction should be retried from the start.
